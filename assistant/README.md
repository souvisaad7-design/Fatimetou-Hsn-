# المساعد الذكي — جمعية عون وسند الخيرية

واجهة Frontend لمساعد افتراضي يجيب عن أسئلة منتسبي الجمعية وزوارها.
تعمل الآن بردود تجريبية (Mock Data) دون أي Backend أو API خارجية، وهي جاهزة للربط لاحقاً دون إعادة تصميم.

## التشغيل

لا تحتاج أي تثبيت أو أدوات بناء. افتح `assistant/index.html` في المتصفح مباشرة،
أو عبر GitHub Pages على المسار `/assistant/`.

## بنية الملفات

```
assistant/
├── index.html          هيكل الصفحة
├── css/style.css       التصميم (ألوان الهوية في متغيرات أعلى الملف)
├── assets/logo.svg     شعار مؤقت — استبدله بشعار الجمعية الرسمي بالاسم نفسه
└── js/
    ├── config.js        كل الإعدادات: الاسم، الترحيب، الاقتراحات، رابط الانتساب، الـ API
    ├── mock-data.js     الردود التجريبية (يجب مراجعتها واستبدالها بالمعلومات الرسمية)
    ├── chat-service.js  طبقة جلب الردود: mock الآن، http لاحقاً
    ├── markdown.js      عرض آمن للتنسيق داخل الردود
    ├── store.js         حفظ المحادثات في متصفح المستخدم
    └── app.js           منطق الواجهة فقط
```

## تخصيص الهوية

- **الألوان:** عدّل `--brand` و `--accent` في أعلى `css/style.css` (وفي كتلتي الوضع الداكن).
- **الشعار:** ضع ملف الشعار الرسمي مكان `assets/logo.svg`، أو غيّر `org.logo` في `config.js`.
- **النصوص:** الترحيب والاقتراحات في `config.js`، والإجابات في `mock-data.js`.

## الربط بالـ Backend لاحقاً

1. في `js/config.js` غيّر `provider: "mock"` إلى `provider: "http"` واضبط `api.endpoint`.
2. الخادم يستقبل:
   ```json
   POST { "messages": [{ "role": "user", "content": "..." }], "stream": true }
   ```
3. ويعيد أحد الشكلين:
   - JSON: `{ "content": "...", "followups": ["..."], "actions": [{ "type": "membership" }] }`
   - أو تدفق SSE: أسطر `data: {"delta":"..."}` ثم اختيارياً `data: {"followups":[...]}`

لا تضع مفاتيح API في ملفات الواجهة؛ مكانها الخادم فقط.

## الربط بموقع الانتساب

- عند جاهزية الموقع، ضع رابطه في `membership.url` داخل `config.js`.
  - يظهر تلقائياً رابط «الانتساب إلى الجمعية» في الشريط الجانبي.
  - يظهر زر «الانتقال إلى صفحة الانتساب» تحت أي رد يحمل `actions: [{ type: "membership" }]`.
- ما دام الرابط `null` لا يظهر أي زر، ويخبر المساعد المستخدم أن الموقع قيد الإعداد.
- يمكن لموقع الانتساب فتح المساعد بسؤال جاهز: `assistant/?q=ما شروط الانتساب`

## ما تتضمنه الواجهة

ترحيب عند الفتح، ستة أسئلة مقترحة، كتابة تدريجية للرد مع مؤشر انتظار، إيقاف الرد،
نسخ الرد وإعادة توليده، أسئلة متابعة بعد كل رد، محادثة جديدة، سجل المحادثات السابقة،
وضع فاتح وداكن، وتصميم متجاوب للهاتف والحاسوب (RTL).
